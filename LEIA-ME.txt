COMO SUBSTITUIR O SITE NO GITHUB

Repositório correto:
https://github.com/rarifavaro/rarifavaro.github.io

1. Abra o repositório acima e entre na aba Code.
2. Clique em Add file e depois em Upload files.
3. Arraste estes quatro arquivos para a tela:
   - index.html
   - style.css
   - script.js
   - favicon.svg
4. O GitHub avisará que index.html já existe. Confirme a substituição.
5. Em Commit changes, escreva:
   Novo Mapa Sagrado Numerológico
6. Marque Commit directly to the main branch.
7. Clique no botão verde Commit changes.
8. Aguarde de 1 a 3 minutos e abra:
   https://rarifavaro.github.io/

O arquivo LEIA-ME.txt não precisa ser enviado ao GitHub. Ele é somente o seu guia.
